# PowerShell Module for Automating vDefend Security Services Platform (SSP) 5.2 Configuration & Instance Deployment

![](icon.png)

## Summary

PowerShell Module to automate vDefend Security Services Platform (SSP) 5.2 Configuration & Instance Deployment.

For detail usage, please refer to this blog post:
* [PowerShell Module for vDefend Security Services Platform (SSP) 5.2 Installer Configuration and Instance Deployment](https://williamlam.com/2026/09/powershell-module-for-vdefend-security-services-platform-ssp-5-2-installer-configuration-and-instance-deployment.html)

## Prerequisites
* PowerShell Core 7.x or later
* vDefend Security Services Platform (SSP) 5.2

## Functions

* Approve-SspInstallerEula
* Connect-SspInstaller
* Connect-SspInstance
* Get-SspInstallerDeployment
* Get-SspInstallerEula
* Get-SspInstallerPackage
* Get-SspInstallerVCenterServer
* Get-SspInstanceNsx
* New-SspInstallerDeployment
* New-SspInstallerPackage
* New-SspInstallerVCenterServer
* New-SspInstanceNsx
* Remove-SspInstallerDeployment
* Remove-SspInstallerPackage
* Remove-SspInstallerVCenterServer
* Remove-SspInstanceNsx
